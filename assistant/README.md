# AI 小助理

一个在终端里运行的 AI 聊天助理,基于 Claude API(模型 `claude-opus-5-5`)。回答逐字流式显示,并且会记住上下文,支持连续追问。

## Windows 一键启动

双击 `assistant\start.bat` 就能启动,它会自动完成以下几步:

1. 查找 Python,没装的话会提示下载地址
2. 第一次运行时自动安装依赖
3. 如果没有 `.env`,自动创建并用记事本打开,填好 Key、保存并关闭记事本后接着启动

想把它变成桌面上的按钮:右键 `start.bat` →“发送到”→“桌面快捷方式”。如果想换个图标,右键这个快捷方式 →“属性”→“更改图标”。

## 私人助手“星期五”

“星期五”是一个更懂你、也能动手办事的私人助手:

- **了解你**:聊天中你提到的称呼、工作、城市、喜好、习惯、目标、重要的日子等,它会自动记下来,下次打开还记得,并按你的习惯给建议。
- **能上网**:需要最新信息(新闻、天气、价格、资料)时会自己搜索、读网页。
- **能动手**:可以在你的电脑上执行命令、读写文件,比如整理文件夹、查看文件内容、把写好的文章保存下来、打开程序或网页。
- **知道现在几点**:每次提问都会附上当前日期和时间,按时段跟你打招呼。
- **性格**:冷静干练,先给结论再给细节,会主动提醒风险和下一步。

### 启动

**装成应用(推荐)**:双击 `assistant\\install-app.bat`,选 1 安装。它会画一个专属图标,在**桌面**和**开始菜单**里放上“星期五”(图形界面),在开始菜单里另外放一个备用的“星期五 命令行”(以前的黑色窗口版),还会问你要不要**开机自动启动**(开机后在后台运行,不弹窗口,Discord 和提醒一直在线)。之后在开始菜单搜“星期五”就能打开,也可以右键固定到任务栏。想撤销就再双击一次,选 2 卸载。

#### 图形界面(科技风页面)

点“星期五”(或双击 `assistant\\friday-app.bat`)会打开星期五自己的窗口,不再是黑色命令行:

- **光球有 5 种样子**(齿轮设定 → 外观 → 光球样子,或点光球旁边的 🎨):经典全息球、反应堆、星系、声波环、原子,颜色跟着主题。在光球上**滚滚轮放大缩小**(触控板两指也行),**按住拖动可以上下左右转**(放手会慢慢停),双击旁边的空白或点 ⟲ 转回正面。大小和样子会记住。
- 中间是一颗 **3D 全息球**:待机时青色缓缓旋转;思考时变蓝、转得更快;**说话时跟着声音起伏、发光**;你在说话(录音)时变成紫色。
- 左边是**系统状态**和**记住的事**,右边是**提醒**和**待办**(含 Google 待办),每 30 秒自动刷新。
- **仪表板**(不花钱,哪一块没设好就不显示):左边有**天气**(现在、体感、最高最低、降雨机会、接下来 6 小时,会下雨的时段变蓝;地点跟“下雨提醒”一样)和**电脑**(CPU、内存、CPU/显卡温度,偏热变黄、太热变红);右边有**今天**(日历上还没过的活动和今天的提醒)、**正在播放**(Spotify 的歌名、封面、进度,可以按上一首/暂停/下一首)和**家里**(Tapo 设备,点一下开关)。窗口看得到时每 10 秒更新;窗口缩小或面板收起时不更新。两边放不下时可以上下滚动,也可以点标题折叠。
- **对话更好用**:不同日期的对话中间有“昨天”“11月10日 星期一”分隔;每个回答下面有“复制”按钮(鼠标移上去才出现);很长的回答先收起一部分,点“展开全部”看完整。
- 下面是对话框:打字回车发送;点🎤说话(停顿 2 秒自动结束);🔊 开关朗读;↺ 开始新话题。
- 需要授权的操作(执行命令、发邮件等)会弹出“授权请求”窗口,点允许/拒绝。
- **关掉窗口,星期五仍在后台运行**(手机 Discord、提醒照常);再点一次“星期五”会重新打开窗口。点右下角的**电源按钮**才会完全退出。
- 运行记录写在 `assistant\\friday.log`,出问题时可以看这里。
- **对话会保存**:窗口里的对话存在 `friday_chat.json`,更新、重启、关机再开都还在(只是显示,不花钱)。发给 Claude 的“工作记忆”会自动瘦身:隔了 30 分钟以上再问,或者重启、开机之后,只带最近 3 轮问答的文字(之前搜到的网页、工具结果都不再重发),接得上话题又不会越聊越贵。点 ↺ 清空当前对话。
- **聊天记录档案**:所有问答都长期存在 `friday_archive.jsonl`(不会自动删除,点 ↺ 也不会清)。问“我之前问过你什么”“上次聊 Apex 你怎么说的”,星期五会自己去档案里搜,只拿找到的几条来看,平时不搜不花钱。
- **聊天记录窗口**(右上角的时钟图标,不花钱):左边按日期列出(今天、昨天……每天几条),右边是那天的问答;上面可以搜索(例如“Spotify”“汇率”,几个词用空格分开就是都要有)。每条可以“复制回答”,或“再问一次”把问题放回输入框。手机 Discord、Telegram 上问的也在。
- **齿轮设定**(右上角):左边分类(常用、声音、外观、提醒、生活、游戏、连接的应用、电脑、备份、安全、花费、账号和版本),右边是那一类的选项;上面的搜索框打几个字(例如“游戏”“Spotify”“提醒”)就把相关的选项都找出来。窗口窄时分类变成上面一排可以左右滑。称呼、声音、汇率等会写进 `.env`,下次启动也有效。
- **Google 登录过期提醒**:Google 应用在“测试中”时,授权大约每 7 天失效一次。星期五会在后台检查:还剩 2 天时开始提醒,过期了也会弹出通知;左边“系统”里 Google 那一行会变黄并显示还剩几天。打开齿轮设定点“**重新登录 Google**”,浏览器会打开登录页,登录完又能用 7 天,不用再双击 google-login.bat。
- **预算和余额**(齿轮设定):填每月预算(马币),用到 80% 提醒,90% 起自动只用 Sonnet,用完就暂停,下个月 1 号恢复。填“哪天充了多少美元”,左边会显示大概还剩多少余额(Claude 没有读余额的接口,所以要你填)。如果你的 Console 能建 Admin Key(`sk-ant-admin` 开头,个人账户要先在 Console → Settings → Organization 设置组织),填进去后花费就用 Console 的真实数字,每半小时更新;Admin Key 只存在你电脑的 `.env` 里,只用来读花费报表。
- **备份到 Google Drive**(齿轮设定):每周自动把记忆、提醒、待办、聊天记录和档案、花费记录、Discord 配对打包上传到 Drive 的“星期五备份”文件夹,保留最近 8 份;也可以点“立即备份”。换电脑或重装后,装好星期五、登录 Google,点“从备份还原”,星期五会下载最新的备份并自动重启换上(还原前的资料会先存成 `friday_before_restore.zip`)。`.env` 里的钥匙和 Google 登录文件不会上传,换电脑时要自己带过去或重新填。
- **全局快捷键**(Windows):在任何地方按 `Ctrl + Alt + F`,星期五的窗口会跳到最前面并开始听你说话(窗口关着就打开一个)。齿轮设定里可以换成别的组合键或关掉;被别的程序占用时会提示。
- **贴图、拖文件**:在星期五的窗口里按 `Ctrl + V` 贴上截图,或者把图片、PDF、Word(.docx)、文字文件(txt、csv、md……)拖进窗口,也可以点输入框左边的回形针选文件。一次最多 4 个、每个 20MB 以内。可以配一句话(“总结一下”“翻译”“帮我记账”),不写也行,它会简单说说内容,是收据就记账。和手机发照片一样,看过一次后不再跟着之后的问题一起发(省钱),要再看就重新贴。
- **选中就问**(Windows):在任何程序里选中一段文字(英文网页、报错信息、看不懂的段落),按 `Ctrl + Alt + Q`,星期五会跳出来:外文帮你翻译成中文,报错告诉你是什么意思、怎么解决,其他内容用简单的话解释。没选中东西时,用剪贴板里已经复制好的文字;你剪贴板里原来的内容会放回去。每用一次就是问一次 Claude 的钱。齿轮设定 → 其他 可以换快捷键或关掉。
- **语音唤醒**(齿轮设定里打开,默认关):麦克风一直在电脑本地听唤醒词(默认“你好星期五”,也可以选“嘿星期五”、只说“星期五”,或者选“自定义…”自己打一个 2~10 个字的中文唤醒词;灵敏度可以调成“严格”减少误判)(离线的 Vosk,不上传声音、不花钱),听到后窗口跳出来并开始录音,接着说的话才交给 Claude。星期五自己在说话或正在录音时会暂停,不会被自己叫醒。第一次打开会自动安装语音组件并下载约 42MB 的中文模型。
- **互动**:
  - **连续对话**:用语音问的问题,她说完后会自动再听几秒(麦克风变青色),直接接着说就行;没说话就安静结束。
  - **说话打断她**:她在说话时你一开口,她就停下来听你说(用麦克风的回声消除,先量一下她自己的声音有多大,比她大才算)。
  - **光球**:跟着鼠标转向你,可以拖着转,点一下光球就开始说话。
  - **快捷按钮**:回答下面有“再详细一点”“简单一点”“换个说法”“记住这个”,点一下就接着问(和平常提问一样计费)。
  - **主动关心**(Windows,不花钱):离开 20 分钟回来会打招呼(顺便说今天还有什么提醒);连续用电脑 2 小时提醒休息,认得出在玩 Apex、Dota 2、PUBG 等游戏;凌晨 1 点后还在用会提醒睡觉。窗口关着时直接读出来,不弹窗打扰游戏。
  - **电脑使用时间统计**(不花钱):星期五每 30 秒看一眼你在用哪个程序、玩哪个游戏(离开 5 分钟以上不算;看视频、打游戏算),记在你自己的电脑上(留 60 天)。问“我今天玩了多久游戏”“这周用了多久电脑”“昨天用了多久电脑”就告诉你;每周花费报告里也会带一句。
  - **打游戏时别打扰**(齿轮设定 → 打游戏时):在玩 Apex、Dota 2 等,或者有程序全屏运行(看视频的浏览器、播放器除外)时,提醒不读出来、不弹置顶窗口,只在右下角弹小通知;游戏离开最前面 1 分半钟后,再把刚才的提醒一起说给你听。手机 Discord 照样会收到。
  - **看视频也算在电脑前**:全屏看视频,或者浏览器、播放器正在放视频时,不碰键盘鼠标也不算离开(不会被当成走开了,“不在电脑前时才推到手机”也不会误推)。
  - **一键游戏模式**:在齿轮设定 → 打游戏时 → “开游戏时自动关掉”里填好要关的程序(可以点“列出程序”看哪些最占内存,点一下就加进去)。之后一开游戏就自动关掉它们;跟星期五说“游戏模式”也会马上关,不用再一个个确认。程序是正常关闭的,有没保存的内容会先问你。
  - **游戏优化**(默认开,不花钱):一开游戏(Apex、Dota 2 或任何全屏游戏),星期五自动把游戏设成高优先级;浏览器、OneDrive/Dropbox 这类云盘同步、Epic/EA 等别的游戏平台、聊天软件降成“低于正常”优先级(照常运行,只是让游戏先用 CPU);电脑有“高性能/卓越性能”电源计划就换过去;星期五自己也让路,文件夹备份等打完再做。Discord、Spotify、OBS、显卡驱动、防作弊和系统程序都不碰,也不关任何程序。打完(离开游戏 90 秒)全部改回原样;星期五中途意外关掉,下次打开也会改回去。说“游戏优化”看状态,“关掉游戏优化/打开游戏优化”开关,齿轮设定 → 打游戏时 也可以开关。有些带防作弊的游戏不让改优先级,那就只做后台让路和电源。
  - **自动认识新游戏**:装在 Steam、Epic、Xbox、Riot、EA、Ubisoft、GOG 游戏文件夹里的程序一开就算游戏(窗口模式也认得);不认识的程序全屏 5 分钟以上,星期五会记成游戏并在右下角告诉你。也可以教它:开着游戏时说“刚才那个是游戏”或“NTE 是游戏”(用你说的名字),说错了就“刚才那个不是游戏”,改名“把 htgame 叫做 NTE”,问“你认识哪些游戏”。存在 `friday_games.json`。
  - **电脑温度**(不花钱):显卡温度用 NVIDIA 驱动自带的工具读;CPU 温度要开着 **Libre Hardware Monitor**(开着就行,在它的 Options 打开 Remote Web Server 会更快)。说“电脑多少度”“CPU 温度”随时回答;打游戏时每分钟看一次,CPU 92°C、显卡 85°C 以上会用右下角小通知提醒(30 分钟最多一次),平时 5 分钟看一次。
  - **游戏后报告**(默认开,不花钱):每局打完(5 分钟以上的局)说一次:打了多久、星期五自己最多用了多少 CPU 和内存、CPU/显卡最热几度、哪个后台程序平均用了 3% 以上(例如“Windows 音频处理 平均 8%”)。问“游戏报告”“刚才那局电脑怎么样”再听一次。齿轮设定 → 游戏 可以关掉。只看不改,不记录你在游戏里做什么。
  - **Steam 愿望单打折提醒**(不花钱):用已经连好的 Steam,每 6 小时看一次愿望单的马来西亚区价格,有游戏打折就在电脑上说、也推到手机(同一次打折只说一次,折扣更大了会再说)。问“愿望单有什么在打折”“Steam 有什么游戏在打折”随时查。Steam 个人资料的“游戏详情”要公开才读得到愿望单。
  - **打游戏时按住说话**(齿轮设定 → 游戏,默认关):选一个键(F7/F8/F9、鼠标侧键、` 键),或选“自定义…”再按一下你想用的键(键盘上几乎任何键、鼠标中键或侧键都行,鼠标左右键不行),打游戏时按住对星期五说话,“嘀”一声开始,放开“嘟”一声就问;她直接用声音回答,窗口不会跳出来、不挡游戏。星期五只是看那个键有没有按着,游戏照样收到这个键,所以选一个游戏里没用到的。按不到半秒不算,最长 30 秒;星期五上锁时不听。第一次用会自动装录音组件。
  - **按住说话更准**:按着键时先把电脑声音(游戏、音乐、浏览器)压到 30%,放开就恢复(你在说话时自己调了音量就不改回去;齿轮设定 → 游戏 可以关掉)。听到的文字会先整理:重复的词去掉(“下午下午三点”)、常听错的名字改回来(“星期无”→星期五、“斯波蒂菲”→Spotify、“迪斯科德”→Discord……)。识别把握度低的时候,她先问“你是说……吗?”,你按住说“对”才做,说“不是”就重说。
  - **游戏里显示字幕**(齿轮设定 → 游戏,默认开):打游戏时按住说话问的问题,回答除了读出来,也在画面下方显示几秒的半透明字幕(点不到、不抢焦点,字越多显示越久)。无边框全屏或视窗模式的游戏看得到;“全屏独占”的游戏会盖住所有窗口,改成无边框全屏就好。
  - **字幕和按住说话可以调**(齿轮设定 → 游戏):字幕位置(下方中间 / 上方中间 / 右下角 / 左上角)、字的大小(小 / 中 / 大)、显示多久(短 / 一般 / 长);按住说话时电脑声音压到原来的多少(10%~60%,默认 30%)。按“试看字幕”不用进游戏就能在画面上看到效果。
  - **一键开黑模式**(齿轮设定 → 游戏 → 一键开黑):说“开黑”,星期五一次打开你选的程序(默认 Discord、Steam)、启动你选的游戏、家里的灯换氛围色、Spotify 放你的游戏歌单、开别打扰;说“不玩了”/“开黑结束”全部恢复(可选顺便关掉她打开的程序)。
  - **打游戏时开东西不会切掉游戏**:在打游戏时叫星期五开程序或网页(例如“开 YouTube”),会缩小着在后台开;新窗口自己跳出来的话,几秒内会被缩回去,游戏放回最前面(YouTube 缩在工作列照样有声音)。打游戏时她也不会显示桌面、不会用开始菜单搜索(会按 Win 键切掉游戏)。按住说话问的问题会告诉 Claude 你在打游戏,别缩小游戏、别切窗口。
  - **打游戏时用声音确认**:按住说话叫星期五做要你“允许”的事时,她会读出来问“要我……吗?”,你再按住说“允许”或“不要”就好(90 秒没回答当成不要),不用切出游戏点窗口。
  - **截图问星期五**(齿轮设定 → 游戏,默认关,键和按住说话一样可以自定义):按一下截下整个屏幕(“嘀嘀”两声),20 秒内按住说话问的问题会带着这张截图(例如“这个任务怎么过”“这句日文什么意思”);没问的话她自动帮你看看画面有什么要注意的。每次算一次问 Claude 的钱。少数全屏独占的游戏可能截到黑屏,改成无边框窗口就好。
  - **Dota 2 选英雄和出装**(不花钱,不用连 Steam):说“对面有痛苦女王和幽鬼,我选什么”,星期五用 OpenDota 公开比赛的数据找对他们胜率最高的 5 个英雄;说“幽鬼出什么装”,给开局、前期、中期、后期最常出的装备。中文名、外号(小黑、蓝猫、PA……)、英文名都认得。也可以用按住说话问。

### 提醒、待办和控制电脑

这些都在你电脑本地运行,不需要注册任何账号,直接跟“星期五”说就行:

**提醒和定时任务**
- “半小时后提醒我喝水”“明天早上 8 点叫我交报告”:到点会弹出置顶提示框、响一声,语音模式下还会读出来。
- “每天早上 9 点给我做个早报,说说天气和今天的待办”:到点后“星期五”自己去查、自己汇报。可以设每天、每个工作日或每周重复。
- **推到手机**:连上 Discord 后,提醒和定时任务的结果会同时私信到你手机的 Discord(在外面也收得到)。齿轮设定 →“提醒推到手机”可以选:总是推 / 只在不在电脑前时推(5 分钟没动键盘鼠标)/ 不推。
- **电脑关机时手机也会响**:登录了 Google 的话,一般提醒会同时放进你的 Google 日历(标题前面有 ⏰),到点手机上的 Google 日历会弹通知,电脑关着也一样;在星期五里取消提醒,日历里那条也会删掉。不想要可以在齿轮设定 → 其他 里关掉。手机要装 Google 日历 App 并开着通知。定时任务(比如早报)要星期五自己去做,还是只在电脑开着时才会执行。
- 星期五自己的提醒**只在“星期五”开着时才会响**(窗口最小化也可以)。关着时错过的一次性提醒,下次打开会马上补上;错过的重复提醒(比如昨天的早报)不补,直接等下一次。
- 定时任务执行时你可能不在电脑前,所以需要你确认的操作(执行命令、写文件)它不会做,会等你回来再说。

**待办清单**:“记一下周五前要交报告”“我还有什么没做”“牛奶买了”。

**控制电脑**:直接说就行,带 🔒 的会先问你同意。

| 类别 | 能做什么 |
|---|---|
| 声音 | 调音量、静音、播放/暂停、上一首/下一首;**切换耳机和音箱**(第一次用时会请你同意安装一个微软官方的小模块) |
| 程序和游戏 | 打开程序(“打开 Discord”;会确认真的开起来了,打不开会换办法,最后问你能不能用开始菜单搜索,不会对着桌面乱点);**打开游戏**(先找 Steam,再找开始菜单,如“打开 Apex”);打开网址;打开文件夹(“打开下载”) |
| 窗口 | 列出窗口、切到某个窗口(“切到 Chrome”)、显示桌面、🔒关闭程序 |
| 游戏模式 | “开游戏模式”:看看哪些程序最占内存,问你关哪些,确认后关掉 |
| 电脑状态 | CPU、内存、硬盘剩余空间、电池、最占内存的程序、IP、网络 |
| 显示 | 亮度(笔记本)、深色/浅色模式、换壁纸、截图(存到“图片\\Friday”) |
| 文件 | 按名字找文件(“找上个月下载的 PDF”)、🔒运行程序文件 |
| 电源 | 锁屏、🔒定时关机/重启(“一小时后关机”)、取消关机、🔒睡眠、🔒清空回收站 |
| 剪贴板 | 读取、写入 |

**看屏幕**:“看看我屏幕上是什么”“这个报错什么意思”,它会截一张图自己看。

**控制鼠标和键盘**:必须在界面上点来点去才能办的事(比如在某个软件里改设置),它可以自己看着屏幕操作鼠标和键盘。为了安全:

- 每个问题第一次接管前会先问你,说明要做什么;
- **你一动鼠标它就马上停下**,把控制权还给你;
- 点“发送、提交、购买、付款、删除”这类不能撤销的按钮前,或按 Alt+F4、Shift+Delete 时,会再单独问你一次;
- 一个问题最多操作 60 步,超过就停下来问你;
- 不会输入密码、验证码、银行卡号,需要登录或付款时请你自己来;
- 定时任务里不能看屏幕、不能动鼠标键盘;
- 操作过程中误打进“星期五”窗口里的字会被清掉,不会被当成你的下一个问题。

能用上面那些一句话的操作或命令完成的事,它不会去点鼠标(更快也更稳)。

| 命令 | 作用 |
|---|---|
| `/todo` | 看待办清单 |
| `/remind` | 看所有提醒 |

**电脑健康提醒**(不花钱,Windows)
- 星期五每 5 分钟看一眼:硬盘剩不到 10%(或不到 15GB)、内存连续 15 分钟用了九成以上(会说出最占内存的程序)、电脑 7 天没重启、下载文件夹堆了 150 个以上文件或超过 10GB,就提醒你。同一件事一天只说一次。
- **照片按月整理**:齿轮设定 → 电脑健康 → 照片按月整理(不填就是“图片”文件夹,也可以填手机照片传到电脑的文件夹),或跟星期五说“帮我把照片按月整理”。最上层的照片和视频按拍摄日期分进“2026-11”这样的子文件夹:先看照片里记录的拍摄时间,没有就看文件名里的日期,再没有就用文件修改时间。10 分钟内刚放进来的先不动,重名不覆盖,点“撤销”全部放回原处。不能整理整个硬盘、用户文件夹、系统文件夹或星期五自己的文件夹。不花钱。
- **病毒扫描**:跟星期五说“扫一下病毒”(快速扫描,几分钟到十几分钟)或“全面扫描”(一两个小时甚至更久,电脑会慢一点),也可以在齿轮设定 → 电脑健康 → 病毒扫描 里点按钮。用的是 Windows 自带的 Microsoft Defender,在后台扫,不会卡住星期五;扫完会告诉你结果。发现威胁、或者是全面扫描,不管推送设定都会推到手机。发现的威胁由 Defender 自己隔离或删除。问“扫描好了没”“电脑有没有病毒”可以看进度、上次扫描时间和实时保护有没有开。装了别的杀毒软件时 Defender 不工作,就没办法用这个功能。不花钱。
- **大文件和重复文件**:齿轮设定 → 电脑健康 → 大文件和重复文件 → “找一找”(或跟星期五说“帮我找占空间的大文件”)。它在你的下载、桌面、文档、视频、图片、音乐文件夹里找出 100MB 以上的大文件,和内容一模一样的重复文件(每组留一个,其余列出来),大约要一两分钟。你勾选要丢的,点“把勾选的丢进回收站”才会动,而且是放进回收站,还能拿回来。不看系统和程序文件夹,不碰星期五自己的文件和钥匙文件。不花钱。
- **一键整理下载文件夹**:齿轮设定 → 电脑健康 → 整理,或者跟星期五说“整理下载文件夹”。最上层的文件按类型分进“图片、视频、音乐、文档、压缩包、安装程序、其他”子文件夹;10 分钟内刚下载的、还没下载完的不动;重名的不会覆盖。整理错了点“撤销上次整理”或说“撤销整理”,文件会放回原处。

**特价和网页追踪**(不花钱)
- 跟星期五说“帮我盯着 Elden Ring 的 Steam 价格,降到 100 块以下告诉我”,或者只说“打折时告诉我”。它会按马币查 Steam 的价格,降价、开始打折(到了心理价)就提醒你,附上商店链接。
- 网页也可以:“盯着这个网页,出现‘有货’告诉我”(只看这个词出现或消失),或者“这个网页有更新告诉我”(内容变化,一天最多说一次)。
- 后台每 2 小时看一次,最多追踪 20 样;说“我在追踪什么”看清单,“不用追踪 XX 了”删掉。
- **限制**:Shopee、Lazada 这类网站要在浏览器里跑程序才显示内容,直接读网页看不到价格,星期五会直说。为了安全,只读公开网站,不读你家里路由器、本机这类内部地址。

**重要邮件马上提醒**(不花钱,要登录 Google)
- 跟星期五说“以后老板的邮件一到就告诉我”“标题有‘面试’的邮件提醒我”,或在齿轮设定 → 其他 填寄件人(名字、邮箱、`@公司域名`)和标题关键词,也可以勾“Gmail 标为重要的也提醒”。
- 星期五每 2 分钟看一次新的未读邮件,对得上就在电脑上说、推到手机,例如“新邮件(来自 boss@abc.com):老板「急:合同」 —— 明天前签好……”。只看寄件人、标题和摘要,同一封只说一次;刚开启时信箱里原来的邮件不算。

**日历事前提醒**(不花钱,要登录 Google)
- Google 日历上的约会、会议,开始前 15 分钟星期五会主动提醒你(窗口读出来 + 推到手机),例如“老板,15 分钟后(14:00)有「开会」,地点:Pavilion KL。那时候可能下雨,出门记得带伞”。有 Google Meet 链接也会提一下。
- 全天的活动、星期五自己放进日历的提醒(⏰ 开头)、你已经拒绝的邀请,不会提醒;同一个活动只提醒一次。
- 齿轮设定 → 其他 可以改成提前 10 / 30 / 60 分钟,或不提醒。打游戏时一样改成右下角小通知。

**会下雨就提醒带伞**(不花钱)
- 每天早上(默认 8:00,齿轮设定 → 其他 可以改成 7:00~9:00 或关掉)星期五看一次吉隆坡的天气预报。今天到晚上 9 点前,哪个时段降雨概率到六成以上,就提醒你带伞,例如“15点到18点雷阵雨(降雨概率 80%)”,也会推到手机 Discord。
- 电脑开得晚也会补看(下午 6 点前);一天只提醒一次。不会下雨就不出声。
- 想看别的城市,在 `.env` 里加 `FRIDAY_WEATHER_PLACE=槟城`。

**这个月钱花在哪里**:说“花费明细”或“这个月 AI 花费”,星期五马上在电脑上算给你看(不花钱):这个月用了多少马币、预算用了几成(连了 Console 就以 Console 为准)、花得最多的几天、各模型各花多少、照这个速度整个月大约多少。问“你这个月花了多少钱”这类说法也行,星期五会自己判断你问的是它的花费还是你自己记的账。

**每周花费报告**(不花钱)
- 每个星期天晚上 9 点后,星期五报告这一周:用了多少钱(马币)、问了 Claude 几次、有几次简单指令没花钱、按模型(Opus / Sonnet / Haiku)各花多少、哪天花最多、比上周多还是少、这个月用了预算的几成,还有你自己这周记了多少账。星期天电脑没开的话,下周一到周三补上。
- 齿轮设定 → 其他 可以关掉。

**每日总结和日记**(不花钱):说“今天总结一下”,星期五说今天用了多久电脑、玩了什么、专注多久、习惯打卡、记了几笔账、问了它几次、记了什么笔记。每天晚上 10:30 后(齿轮设定里可以改时间或关掉),第一次坐在电脑前时会主动总结,再问你“今天过得怎么样”。说“日记:今天……”就记下来(凌晨 3 点前写的算前一天)。之后可以问“昨天的日记”“上周三的日记”“11 月 5 号的日记”“日记里找 火锅”。

**购物清单**(不花钱):说“要买牛奶、鸡蛋和面包”“洗发水加到购物清单”。在外面用手机 Discord / Telegram 问“要买什么”,买好说“牛奶买了”就划掉,说“牛奶买了 8 块”还会顺便记一笔账。“不用买面包了”“清空购物清单”。

**桌面小光球**(Windows):点右上角的 ⧉ 按钮(或齿轮设定 → 外观 → 桌面小光球,或说“显示小光球”),桌面上就只多一颗会发光的小球,浮在所有程序最上面,球以外完全透明(点到透明的地方会直接点到后面的程序)。点一下就开始说话,再点一下停;按住可以拖到喜欢的位置(会记住);右键会弹出小选单:说话 / 打开星期五窗口 / 收起小光球(也可以说“收起小光球”)。在听、在想、在说时动法不一样,颜色跟着主题。打开后下次开星期五也会自动出来。

**迷你悬浮窗**(不是 Windows 时):点右上角的 ⧉ 按钮,会弹出一个小窗口,永远浮在所有程序最上面(打游戏、看视频时也看得到)。里面有一个小光球,显示星期五在听、在想还是在说,还有专注倒计时、睡前定时和最后一句回答;点小光球就能说话。可以拖到屏幕角落,点 ⧉ 或关掉小窗口就收起来。要用新版 Edge 或 Chrome。

**睡前定时**(不花钱):说“30 分钟后停音乐”“半小时后关掉音乐”“听完这首就停”,窗口上方会显示 🌙 倒计时;Spotify 在放的话,最后 60 秒会慢慢变小声再暂停,停完把音量调回原来的(下次放歌不会没声音);别的播放器就按“停止”键。“1 小时后让电脑睡眠”“1 小时后关机”会先问你同意。说“定时还剩多久”“取消定时”。

**读给我听**(不花钱):说“读给我听”加网址(或把网址贴进窗口说“读一下这篇”)、“把复制的文字读给我听”、“读第 1 个文件”(先用找文件找到),星期五用自己的声音一段一段读,读完一段接下一段。读的时候直接开口就会停下来听你说:“暂停”“继续”“跳过这段”“上一段”“从头再读”“读快一点”“读慢一点”“读到哪里了”“别读了”。能读网页文章、PDF、Word(.docx)、txt。读的内容不会交给 Claude。只能在电脑的窗口里听(右下角喇叭要开着)。

**新闻简报**(不花钱):说“今天有什么新闻”(马来西亚 5 条 + 国际 3 条)、“科技新闻”“财经新闻”“体育新闻”“娱乐新闻”“国际新闻”“关于股市的新闻”。每条有编号,说“第 3 条详细说说”,Claude 会去搜那条新闻再讲(花一点点)。早安简报里也会带 3 条马来西亚新闻(.env 里写 `FRIDAY_BRIEF_NEWS=off` 可以不要)。新闻来自 Google 新闻的公开 RSS。

**口译模式**:说“开始口译 英文”(也可以马来文、淡米尔文、粤语、日文、韩文、泰文、印尼文、越南文、法文、德文、西班牙文),之后你说中文,星期五用那种语言的声音说给对方听;对方说的,翻成中文说给你。一来一回轮流说(你说完轮到对方),配合“连续对话”不用一直按按钮。说“结束口译”停止。每句用便宜的 Haiku 翻译,一句不到一分钱。

**重要文件夹自动备份**(不花钱):齿轮设定 → 重要文件夹备份,填要备份的文件夹(一行一个,例如文档、照片)和备份到哪里(最好是另一个硬盘或移动硬盘,例如 `E:\星期五备份`)。每天 10 点后第一次检查时自动备份,只复制新的和改过的;原文件删了,备份里的还在;改过的文件旧版本移到 `_旧版本\日期` 里留 30 天。一下子很多文件同时改了(像中了勒索病毒),这次就不备份,马上提醒你(也推到手机),确认是你自己改的再点“照样备份”。移动硬盘没插就等下次,超过 7 天没备份会提醒。说“马上备份文件夹”“备份状态”也行。

**连接的应用**(齿轮设定 → 连接的应用):
- **Steam**:在 steamcommunity.com/dev/apikey 免费申请网页 API 钥匙(网域名称随便填,例如 localhost),和你的 Steam 个人资料网址一起填进去(个人资料的“游戏详情”和“好友列表”要设成公开)。之后可以问“我最近玩了什么”“Apex 我一共玩了多久”“我玩最久的游戏”“Steam 好友谁在线”。钥匙只存在你的电脑,不要发给任何人。开游戏本来就能用(“打开 Dota 2”)。
- **NVIDIA**:有 NVIDIA 显卡就自动能用:“显卡温度”“显卡状态”;打游戏时说“刚才那段存下来”(存精彩片段,要先在 NVIDIA App 打开“即时重放”)、“开始录像”“停止录像”“游戏截图”。显卡到 85°C 以上会提醒(打游戏时是右下角小通知)。
- **Spotify 点歌**:在 developer.spotify.com/dashboard 建一个免费应用,Redirect URI 填齿轮设定里显示的那个网址(像 `http://127.0.0.1:端口/spotify/callback`),勾选 Web API,把 Client ID 填进齿轮设定,再点“登录 Spotify”。之后说“放周杰伦的晴天”“放我的歌单 开车”“放我喜欢的歌”“现在放的是什么歌”。Spotify 在放时,“下一首”“上一首”“暂停”“继续”会直接叫 Spotify 做,浏览器里开着 YouTube 也不会被抢走。Spotify 只让 Premium 账号用程序直接播放;免费账号会把歌在 Spotify 里打开,点一下播放。
- **Dota 2 战绩**:连好 Steam 就能用(免费的 OpenDota)。要在 Dota 2 的 设置 → 选项 → 社交 里打开“公开比赛数据”(Expose Public Match Data)。可以问“刚才那局怎么样”“最近 10 局赢了几局”“我哪个英雄胜率最高”“我的 Dota 段位”。打完一局 Dota,几分钟后星期五会主动报这局的输赢、KDA、GPM。不花钱。
- **Apex 地图和战绩**:在 portal.apexlegendsapi.com 免费申请钥匙(用 Discord 登录),和你的 EA 名字、平台一起填进齿轮设定。之后问“现在 Apex 是什么地图”“下一张图几点换”“我的 Apex 排位分”。不花钱。
- **Telegram**:在 Telegram 找 @BotFather,发 `/newbot`,按提示给机器人取名字,它会给你一把钥匙(像 `123456789:AAH...`),贴进齿轮设定 → 连接的应用 → Telegram 机器人钥匙,点保存。然后在 Telegram 私聊你的机器人,发齿轮设定里显示的 6 位配对码。之后就和 Discord 一样:打字、发语音、发照片(收据记账)、收提醒、要确认的事在 Telegram 上问你;手机遥控锁(验证器数字)也一样有效。只认私聊,群组里不理;猜错配对码 5 次拉黑。钥匙只存在你的电脑,不要发给任何人。
- **Tapo 智能家居**:先在 Tapo App 里打开 我 → 第三方服务 → 第三方兼容(Third-Party Compatibility),再把 Tapo App 的登录邮箱和密码填进齿轮设定 → 连接的应用,点保存(第一次会在后台装控制组件,一两分钟)。电脑和灯、插座要连同一个 Wi-Fi。之后说“开灯”“关灯”“把客厅灯打开”“关掉电脑插座”“全部关掉”“灯调暗一点”“客厅灯亮度调到 80”“灯换成暖光”“把灯换成蓝色”“家里哪些灯开着”。在手机 Discord / Telegram 上说也行。Google Home、Apple Home 里的同一个设备会跟着变(这两个本身没有给 Windows 用的接口,所以是通过 Tapo 控制)。密码只存在你的电脑。不花钱。
- **微信**:说“打开微信”“切到微信”。微信没有给个人用的接口,用程序替你读、发微信消息会违反微信规定、可能被封号,所以星期五不做。

**剪贴板历史**(不花钱):星期五记住最近复制过的 50 段文字。说“剪贴板历史”列出来(带编号),“复制第 3 个”就放回剪贴板,直接 Ctrl+V;“刚才复制的网址”“刚才复制的电话”直接拿回最近的那个;“剪贴板里找 关键词”。看起来像密码、钥匙、验证码的不记,密码管理器(KeePass、1Password、Bitwarden 等)复制的密码也不记。只存在这台电脑,不备份到 Google Drive。齿轮设定 → 电脑健康 里可以关掉或清空。

**习惯打卡**(不花钱):跟星期五说“每天喝 8 杯水,10 点、1 点、4 点提醒我”“每天早上 9 点、晚上 9 点提醒我吃药”就记下来。到点还没做够会提醒(做够了就不吵你)。做完说“水喝了”“喝了两杯水”“药吃了”“运动打卡”就打卡,会告诉你今天几次、连续几天达标。说“今天打卡情况”“这周打卡情况”看完成度;每周花费报告里也会带上每个习惯这周达标几天。说“撤销喝水打卡”可以撤销一次。

**网速测试和断网提醒**(不花钱):说“测一下网速”,星期五用 Cloudflare 测速服务在后台测下载、上传和延迟(约 20 秒,用掉 30MB 左右流量),测完告诉你,也说延迟打游戏够不够。另外每 20 秒看一次网络:断了一分钟会在电脑上说“网络好像断了”,恢复了告诉你断了多久(也推到手机)。说“今天断了几次网”“这周断了几次网”看记录(只算星期五开着的时候)。

**汇率**(不花钱):说“100 美金是多少马币”“1000 马币换人民币多少”“新币汇率”马上算。说“新币到 3.5 告诉我”“美金跌破 4.3 提醒我”,星期五每小时看一次,到了就提醒并推到手机(提醒一次就取消)。说“汇率提醒”看设了哪些,“取消新币汇率提醒”取消。汇率是免费公开数据(每天更新一次的参考价),和银行、换钱店的买卖价会有一点差别。

**早安简报**(不花钱):每天早上 5 点到 12 点之间,第一次坐到电脑前,星期五会一次说完今天要知道的事:天气(会不会下雨、紫外线)、Google 日历上今天的活动、今天的提醒、到期和过期的待办、3 天内的生日纪念日、快到期的账单、昨天以来的未读邮件(重要的会说寄件人和标题)、昨天记的账和星期五花了多少。哪一项拿不到就跳过。随时说“早安”“今天有什么安排”也能马上听一次。不想每天自动说,在齿轮设定里关掉“早安简报”。

**账单到期提醒**(不花钱):跟星期五说“每个月 15 号交房租 800”“电费每月 20 号到期”“路税每年 3 月 1 日到期”就记下来。到期前 3 天、当天各提醒一次,过期 2 天还没付再提醒一次(早上 8 点后,也推到手机)。付了说“电费付了”或“电费付了 135 块”,这一期就不再提醒,还会顺便用马币记一笔“账单”。说“账单”或“这个月还有什么账单没付”看接下来要付的。

**专注模式 / 番茄钟**(不花钱):说“专注”(25 分钟)、“专注 50 分钟”或“专注一个小时”开始,窗口上方会显示倒计时。专注时,星期五自己主动要说的事(下雨、报告、生日、账单、新邮件……)先压着,时间到再一起说;你自己设的提醒和日历活动照常提醒。时间到叫你休息 5 分钟,休息完再叫你。说“还剩多久”“停止专注”“今天专注了多久”“这周专注了多久”。

**找文件**:说“我昨天下载的那个 PDF 在哪”“找一下名字有报价单的 Excel”,星期五在下载、桌面、文档、图片、视频、音乐、OneDrive 和 C 盘以外的硬盘里按文件名找(不看文件内容),列出最新的 20 个,带编号。说“打开第 1 个”就用默认程序打开,也可以叫它在文件夹里显示,或者发到手机。说“找文件 报价单”这种固定说法不问 Claude,不花钱;其他说法要问 Claude 理解你的意思(花一点点)。不找系统和程序文件夹;钥匙、密码文件不列出来;程序和脚本(.exe、.bat 等)不替你打开,只在文件夹里显示。

**生日和纪念日**(不花钱)
- 跟星期五说“妈妈的生日是 3 月 12 号,1961 年出生”“我们的结婚纪念日是 6 月 1 日”,它会记下来。Google 联系人里填了生日的人,也会自动算进去。
- 提前 3 天和当天(早上 8 点后)会提醒你,电脑上说、也推到手机,例如“3 天后(3/12)是妈妈的生日(65 岁)”,还会问你要不要帮忙想祝福的话。
- 问“最近有谁生日”“接下来有什么纪念日”就列出接下来 30 天的重要日子。

**语音速记本**(不花钱)
- 说或打“记一下:明天打电话给阿明”“备忘 下周三交报告”,星期五在电脑上直接存好,回你“记好了(#1)”。
- “我的笔记”看最近 10 条;“笔记里有没有阿明”“找笔记 报告”按关键词找;“删掉刚才那条笔记”。这些都不花钱。问得更模糊,像“我上周记的那个灵感是什么”,星期五会自己去找(这种要问 Claude,花一点点)。
- 登录了 Google 的话,每条笔记也会接到 Google 文档“星期五笔记”的最后,手机上打开 Google 文档就看得到。笔记存在 `assistant/friday_notes.json`,也会跟着备份。不要在笔记里记密码。
- “记住……”是星期五的长期记忆,“记一下……”是你的笔记,两个不一样。

**语音记账**
- 说一句“午饭 15 块”“Grab 12 块”“昨天的晚饭 28 块”,星期五就用马币记下来,自动分类(餐饮、交通、购物、娱乐、账单、医疗、其他)。记错了说“删掉刚才那笔”。
- “这个月花了多少”“看看 10 月的账”:给你总数、分类占比、最大的一笔,和上个月比。左边“系统”里也会显示本月记账。
- **月底汇总**:每月最后一天晚上 9 点后,星期五会主动报这个月的账(也推到手机 Discord);那天电脑没开的话,下个月第一次打开时补上。
- 登录了 Google 的话,整本账会同步到 Google 云端硬盘里的表格“星期五记账”,手机上也能看。账本本身存在 `assistant/friday_ledger.json`,也会跟着备份。

提醒和待办保存在 `assistant/friday_reminders.json`、`assistant/friday_todos.json`(和记忆文件放在同一个文件夹,不会提交到 Git)。

### Google 服务(日历、Gmail、待办、通讯录、云端硬盘、文档、表格、YouTube)

授权一次之后,就可以跟“星期五”说:

| 服务 | 说法示例 |
|---|---|
| 日历 | “我明天有什么安排”“周五下午三点加个看牙” |
| Gmail | “有没有重要的新邮件”“帮我回复这封邮件说好的” |
| 待办(Google Tasks) | “记一下周五前交报告”“我还有什么没做”,手机上的 Google Tasks 也能看到 |
| 通讯录 | “发邮件给阿明说周末打球”(自动查阿明的邮箱) |
| 云端硬盘 | “找一下我的简历”“把桌面上这个文件传到云端硬盘”“把那个表格下载下来” |
| 文档 | “把刚才写的周报存成 Google 文档” |
| 表格 | “帮我建个记账表”“记一笔:午饭 15 块” |
| YouTube | “我订阅的频道今天有什么新视频”“找一下 Apex 新赛季攻略” |

每天的早报也会顺便讲今天的日程、待办和未读邮件。接上 Google 后,待办清单改用 Google Tasks(`/todo` 也会显示 Google Tasks 里的内容)。

- **发邮件、回邮件每次都要你确认**(就算选过“都允许”也一样),确认时会显示收件人、主题和正文;不确定的可以让它先存草稿。
- 邀请别人参加活动、删除活动也会先问你。
- 定时任务里只能看,不能发、不能删。
- 通讯录只读;云端硬盘不会删除或分享文件。
- 邮件和文件是别人写的,它只把内容转述给你,不会照着里面的要求去做事。

**第一次设置(大约 15 分钟,只需要做一次):**

1. 打开 <https://console.cloud.google.com/>,用你的 Google 账号登录,新建一个项目(名字随便,比如 Friday)。
2. 在顶部搜索框分别搜索并 **启用(Enable)** 这几个接口:**Gmail API**、**Google Calendar API**、**Google Tasks API**、**People API**、**Google Drive API**、**Google Docs API**、**Google Sheets API**、**YouTube Data API v3**。
3. 左侧菜单进入 **Google Auth Platform**(或“API 和服务 → OAuth 同意屏幕”),按提示配置:应用名称随便填,用户类型选 **外部(External)**,联系邮箱填你自己的。
4. 在 **目标对象(Audience)** 里把你自己的 Gmail 加为 **测试用户**;然后点 **发布应用(Publish app)** 改成“正式版”,这样授权不会每 7 天过期一次。(如果发布后登录时被拦住,就保持“测试”状态,只是每 7 天要重新双击一次 `google-login.bat`。)
5. 进入 **客户端(Clients)**,创建 OAuth 客户端,类型选 **桌面应用(Desktop app)**,创建后点 **下载 JSON**。
6. 下载的文件(名字类似 `client_secret_xxxx.json`)留在“下载”文件夹就行,**不用改名**:下一步会自动找到它,复制到 `assistant` 文件夹并改名为 `credentials.json`。
7. 双击 `assistant\google-login.bat`,浏览器会打开 Google 登录页。因为这个应用是你自己建的、没给 Google 审核,会看到“Google 尚未验证此应用”,点 **继续**(或“高级 → 转至 Friday”),再**勾选所有权限**并允许。(以后加了新功能需要新权限时,“星期五”会提示你再双击一次 `google-login.bat`。)
8. 窗口里显示出你最近的日程和邮件,就说明成功了。之后打开“星期五”就能用。

`credentials.json` 和授权后生成的 `google_token.json` 相当于钥匙,不要发给别人(已被 `.gitignore` 忽略,不会提交到 Git)。想取消授权,删掉 `google_token.json`,并在 <https://myaccount.google.com/permissions> 里移除这个应用。

### 用手机 Discord 找“星期五”

设置好以后,在手机的 Discord 上私信你的机器人,电脑上的“星期五”就会回复你,出门在外也能让它查东西、看日程、在家里的电脑上办事。前提是电脑开着、“星期五”在运行(窗口最小化也可以)。

**发照片**
- 直接在 Discord 发照片给星期五(一次最多 4 张),可以配一句话,也可以只发照片。
- **收据、账单、发票**:它会看清金额、商家、日期,用马币记账(外币先大约换算,备注原来的金额),记完简短确认;看不清金额会问你,不会乱猜。
- **其他照片**:外文菜单、路牌帮你翻译;报错画面帮你看是什么问题;不认识的东西帮你认。
- 照片会先缩小再发给 Claude(省钱、也比较快);看过一次后就不再跟着之后的问题一起发,所以要它再看同一张,请重新发。每张照片大约多花一次普通提问的钱。

**截图和文件发到手机**
- 在外面私信“截个图给我看”,星期五把电脑屏幕的截图直接发到 Discord;“把桌面上的报告发给我”,它会找到文件发过来(最大 10MB,更大的会建议你用 Google 云端硬盘)。
- 发文件前要你确认(开了手机遥控锁就要输入验证码);钥匙、密码文件一律不发。只在私信里发,服务器频道里不发。在电脑上叫它发,会私信到你的手机。

**安全**
- 只认配对过的账号(可以是你的几个号):配对码只能在电脑上生成,别人私信机器人一律忽略;
- 在哪里说话它会回:**私信**机器人;在服务器里名字带 `friday` 或 `星期五` 的频道说话;或在其他频道 **@FRIDAY**。在普通频道和朋友聊天时它不会插嘴;
- 需要确认的操作(执行命令、关程序、发邮件……)会发到 Discord 问发消息的那个号,回复 `y` 才执行,2 分钟不回复算拒绝;
- 机器人的 Token 保存在 `assistant/.env`,相当于机器人的密码,不要发给别人。

**设置(大约 5 分钟)**
1. 双击 `assistant\\discord-setup.bat`,按窗口里的提示做:
   - 打开 <https://discord.com/developers/applications>,点 **New Application**,名字填 `Friday`;
   - 点左侧 **Bot** → **Reset Token** → **Copy**;
   - 回到窗口,点右键粘贴 Token,按回车。
2. 浏览器会打开邀请页面:选一个你自己的服务器,点 **授权**。(要私信机器人,你们至少得在同一个服务器里;没有的话先在 Discord 左侧点 **+** 新建一个。)
3. 打开“星期五”,窗口里会显示 **6 位配对码**。在 Discord 的服务器成员列表里点机器人头像 → 发私信,发送这个配对码,看到“配对成功”就完成了。

**语音消息**:在 Discord 里按住麦克风按钮说话、松开发送,“星期五”会先回一句“🎤 听到:……”,再回答,并附上一段“晓晓”读出来的语音(点一下就能播放)。确认操作时说“可以”也算同意。识别用的引擎和电脑上的语音模式一样(`FRIDAY_STT`),朗读的声音用 `FRIDAY_TTS_VOICE`。

**想在服务器频道里用(不 @ 它也回)**:在开发者页面的 **Bot** 里,往下找到 **Message Content Intent**,打开并保存;然后在你的服务器里新建一个名字带 `friday` 的频道(比如 `#friday`),在那里说话就行。没打开这个开关的话,只能私信或 @它。

**有好几个 Discord 号?** 都可以配对:在“星期五”窗口输入 `/discord pair` 生成新的配对码(10 分钟内有效、只能用一次),用另一个号私信机器人发送这个码就行。

| 命令 | 作用 |
|---|---|
| `/discord` | 查看已配对的账号 |
| `/discord pair` | 生成配对码,添加一个新账号 |
| `/discord remove 编号` | 移除某个账号 |

### 云端模式:电脑关机也能用

云端的星期五是电脑的**后备**:电脑开着时由电脑回答;电脑关机、睡眠或断网超过 3 分钟(在窗口里点电源按钮关掉的话是马上),云端就接手回答手机 Discord、按时提醒;电脑回来后,云端这段时间记住的事、提醒、待办和聊过的内容会自动合并回电脑。电脑每分钟把记忆、提醒、待办、对话、Google 登录同步给云端,所以云端也认得你、能查日历和 Gmail。云端碰不到你的电脑,所以不能开程序、看屏幕。

两边用 HTTPS 连接:云端用自己生成的证书,电脑只认这一张(配对码里有它的指纹),再加一串只有你有的密码。

**在 Google Cloud 免费主机(e2-micro)上安装:**

1. 打开 console.cloud.google.com,选你之前做 Google 登录的那个项目。左上角菜单 → **结算**,关联一个结算账号(要绑卡;可以顺便在“预算和提醒”里设一个 US$1 的预算提醒,万一有收费马上知道)。
2. 菜单 → **Compute Engine → 虚拟机实例** → 启用 API → **创建实例**:
   - 名称:`friday`
   - 区域:`us-central1`、`us-west1` 或 `us-east1`(只有这三个区域有免费额度)
   - 机器类型:**e2-micro**
   - 启动磁盘:点“更改”,选 **Ubuntu 24.04 LTS**,磁盘类型选 **标准永久性磁盘**,大小 10~30 GB
   - 防火墙:勾选 **允许 HTTPS 流量**
   - 点 **创建**
3. 实例建好后,点它那一行的 **SSH**,会打开一个黑色的网页终端。把下面几行逐行贴进去(每行贴完按回车):
   ```bash
   sudo apt-get update && sudo apt-get install -y unzip
   curl -L -o friday.zip https://github.com/weonepiece0245-a11y/AutoActionPro/archive/refs/heads/claude/zealous-thompson-eoxylu.zip
   unzip -q friday.zip && cd AutoActionPro-claude-zealous-thompson-eoxylu/assistant
   sudo bash server-install.sh
   ```
   它会问你 Claude API Key 和 Discord Token(贴上时屏幕上看不到,正常),然后自动装好,最后显示一串 **FRIDAY-** 开头的配对码。
4. 在电脑上星期五的 **齿轮设定 → 云端星期五**,把配对码贴进去,点“连接”。左边“系统”会多一行“云端 待命”。
5. 试一下:在星期五窗口点电源按钮关掉,用手机 Discord 问一句,云端会回答;再打开电脑上的星期五,刚才的对话会出现在窗口里。

- 电脑上点“检查更新”时,云端也会一起更新。
- 不要“停止”这台虚拟机:停止再开机,公网 IP 可能会变,要在 SSH 里运行 `cd ~/AutoActionPro-*/assistant && sudo -u friday venv/bin/python friday_cloud.py code` 拿新的配对码。重新启动(reboot)不影响。
- 查看云端运行记录:SSH 里运行 `journalctl -u friday -f`。
- 用 DigitalOcean 等其他 Ubuntu 服务器也一样:把第 3 步的几行在服务器上运行就行(要开放 443 端口)。

### 语音对话

双击 `assistant\friday-voice.bat` 就能用嘴和“星期五”聊天,它的回答会读出来。第一次运行会自动安装语音相关的依赖。

- **说话**:直接按**回车**,看到“我在听,请说话……”后对着麦克风说。说完**停顿 2 秒**自动结束,或者**再按一次回车**立刻结束。说话中间短暂想一下、声音变小都不会被打断。如果你说话常常停下来想,在 `assistant/.env` 里加一行 `FRIDAY_PAUSE=3`(或加参数 `--pause 3`)把停顿时间调长。
- **打字**:照常输入文字再回车,和平时一样。
- **结束**:说“退出”或“再见”,或者按 Ctrl+C。朗读时按 Ctrl+C 可以打断朗读。
- 语音模式下,“星期五”的回答会更口语、更简短;长内容(文章、代码)会存成文件告诉你位置。
- 执行命令、写文件仍然要你在键盘上按 `y` 确认,语音不能代替确认。

**语音识别引擎**(用 `--stt` 参数或在 `.env` 里写 `FRIDAY_STT=` 选择):

| 引擎 | 说明 |
|---|---|
| `google`(默认) | 在线识别,免费、准确度好,**需要能访问 Google** |
| `vosk` | 离线识别,不需要联网,准确度稍差;第一次使用会自动下载约 42MB 的中文模型到 `assistant/models/` |

如果识别时提示“在线语音识别连接失败”,在 `assistant/.env` 里加一行 `FRIDAY_STT=vosk` 改用离线识别。

**朗读的声音**默认是微软 Edge“大声朗读”同款的神经网络语音“晓晓”,听起来很自然,需要联网;万一连不上,会自动改用系统自带的语音读,不会没声音。

想换个声音,在 `assistant/.env` 里加一行 `FRIDAY_TTS_VOICE=名字`(或运行时加 `--tts-voice 名字`):

| 名字 | 声音 |
|---|---|
| `xiaoxiao`(默认) | 晓晓,女声,温暖自然 |
| `xiaoyi` | 晓伊,女声,活泼 |
| `yunxi` | 云希,男声,阳光 |
| `yunjian` | 云健,男声,沉稳 |
| `yunyang` | 云扬,男声,新闻播报风格 |
| `hsiaochen` | 晓臻,台湾女声 |

不想联网朗读,写 `FRIDAY_TTS=system`(或加 `--tts system`),改用系统自带的语音(离线)。系统语音没有中文时,在 Windows 的“设置 → 时间和语言 → 语音 → 管理语音 → 添加语音”里添加“中文(简体,中国)”。

在线语音用的是 Edge 浏览器朗读功能背后的免费接口,不是正式的付费服务,将来有可能失效;失效时会自动改用系统语音。

**每句话开头被吞掉?** 很多扬声器、蓝牙耳机没声音时会休眠,来声音时要半秒到一秒才醒,开头就丢了。语音模式会在后台一直播放听不见的极小声音让设备保持唤醒(默认开启;在 `.env` 里写 `FRIDAY_KEEP_AUDIO_AWAKE=0` 可关闭)。

**没声音或听不到我说话?** 双击 `assistant\voice-test.bat` 做个检查:它会列出系统里的朗读语音,分别用系统语音和在线语音各读一句,再录一句话看能不能识别。

命令行用法:`python assistant/assistant.py --persona friday --voice`(普通小助理也可以加 `--voice`)。手动安装语音依赖:`python -m pip install -r assistant/requirements-voice.txt`。

### 稳定性守护

- **崩溃、卡死会自动重开**:星期五打开时会在后台开一个小小的守护程序(没有窗口)。星期五每 30 秒“报平安”一次;万一它意外关掉,或者超过 10 分钟没反应,守护会自动把它重新打开(不弹窗口,像开机自动启动那样),重开后窗口里和手机上都会告诉你发生了什么。15 分钟内最多重开 3 次,还是不行就停下来,不会一直开开关关。
- **窗口叫不动 2 分钟就重开**:守护每 30 秒敲一下星期五的窗口服务,连续 4 次(大约 2 分钟)都没回应,就当它卡住了,直接结束再重新打开,不用自己去任务管理器。
- **更新后起不来就退回上一版**:“检查更新”换新文件前,会把旧文件先存一份到 `assistant/_update_backup`。更新完 30 分钟内星期五起不来、闪退或卡住,守护会先把旧文件放回去再打开,并告诉你“已经自动退回上一版”(只退一次;你的私人文件不会动)。之后可以再点一次检查更新,等修好的版本。
- **桌面小光球在自己的小程序里跑**:小光球就算卡住,也只有它自己卡,星期五和检查更新照常;星期五关掉时小光球也会自己收起来。
- 守护程序本身更新后,会自己换成新版继续看着。
- **自我检查**:半夜自动更新完 3 分钟后,星期五把常用的功能试跑一遍(只读、不花钱):天气、Spotify 连线、开程序要用的开始菜单清单、提醒、Google、记忆、Claude 钥匙、Discord。没设定的跳过。哪个坏了,早安简报里第一句告诉你,也推到手机(没开早安简报的话,早上回到电脑前时说)。随时说“自我检查”也会马上做一次。
- **半夜自动更新**(齿轮设定 → 账号和版本,默认开):凌晨 3~5 点电脑开着、你 20 分钟没在用、没在打游戏时,星期五自己检查更新,有新版本就装好重开(新版本起不来会自动退回上一版)。早上你回到电脑前时,告诉你昨晚更新了什么。电脑关机或睡眠时就不会更新,照旧可以手动点“检查更新”。
- 想真正关掉星期五,请点窗口右下角的**电源按钮**;用“任务管理器”强制结束的话,守护会以为它崩溃了,又把它打开。不想要守护,在 `.env` 里加一行 `FRIDAY_GUARD=off`。
- **要你处理的事马上推到手机**(不管“提醒推到手机”怎么设):Claude 钥匙失效、账户余额用完、余额快用完(低于 US$3)、预算到 80%/90%/用完、Google 登录快过期或已过期。
- **钥匙到期提醒**:Console 建的钥匙有到期日。在齿轮设定 → 其他 填“Claude 钥匙到期日”,提前 3 天、1 天和当天都会提醒你(也推到手机)。

### 安全

- **执行命令和写文件之前一定会先问你**,你输入 `y` 才会执行;输入 `a` 表示本次运行期间都不再询问(关掉程序后恢复询问)。窗口版的“10 分钟内都允许”只管 10 分钟,点“新话题”也会作废;确认框默认停在“拒绝”,打字时误按 Enter 不会变成允许。读取文件、搜索网页不需要确认。
- **Discord 服务器频道里**:频道里的人都看得到回答,所以星期五在频道里不说邮件、日历、记忆、记账等私人内容,需要确认的操作也一律不做,会请你改用私信。
- `friday.log` 超过 5MB 会自动换新(旧的留一份 `.old`),窗口的口令不写进记录。
- 命令默认在你的用户主目录下执行,可以用 `--workdir 目录` 换成别的目录。
- 不想让它联网,加参数 `--no-web`。
- **钥匙和密码绝不碰**:`.env`、Google 登录、Discord 设置、SSH 钥匙、浏览器保存的密码和登录状态、密码库(.kdbx)等,星期五读文件、执行命令时一律拒绝,不管是谁让它做的。
- **不改自己、不偷偷开机运行**:星期五不会往自己的程序文件夹、开机自动启动的文件夹里写东西,防止有人借它塞进会自动运行的程序。
- **网页、邮件、文件里的“指示”不照做**:读到的内容都标成“外部资料”;像“忽略之前的指示”“以后不用确认”这种话也不会被记进记忆。
- **Discord 配对更严**:只能私信配对(频道里发的配对码无效);一个账号猜错 5 次就被拉黑;所有人加起来猜错 20 次,配对码直接作废。有新账号配对成功,会马上通知你(窗口 + 手机)。
- **窗口防护**:窗口只接受本机的请求,别的网站发来的一律拒绝;页面加了安全规则(CSP),不能被嵌进别的网页,也不能执行外来的程序。3D 光球用的程序库第一次会存到本机(`assistant/web/vendor/`),以后都用本地的,而且每次都检查有没有被改过。
- **手机遥控锁**(齿轮设定 → 安全 → 开启):用手机上的验证器 App(Google Authenticator、Microsoft Authenticator 都可以)。开启后:Discord 超过 2 小时没用,要先私信 App 里“星期五”现在的 6 位数字才会理你(你先发的那条消息,解锁后会接着处理);执行命令、发邮件、控制电脑这类要确认的操作,也要回复 6 位数字,回复 y 不算。数字每 30 秒换一次、用过就作废,所以就算 Discord 账号被盗、聊天记录被人看到也没用。连续错 3 次手机遥控就暂停,并马上通知你,要在电脑上点“恢复手机遥控”。手机丢了:在齿轮设定里点“关闭”,或者删掉 `.env` 里 `FRIDAY_REMOTE_TOTP` 那一行。
- **窗口锁**(齿轮设定 → 安全):先设一个 4~8 位数字的 PIN,再选“离开多久自动锁窗口”(5 / 10 / 30 分钟)。离开电脑超过这个时间,星期五的窗口就锁住:对话、记忆、提醒都看不到,也不能打字、说话、点允许,要输入 PIN 才解锁。右上角的锁可以马上上锁。PIN 连错 5 次要等 5 分钟,并通知你。PIN 只存加密后的样子,不存原文;忘了 PIN 就删掉 `.env` 里 `FRIDAY_LOCK_PIN` 那一行再重开星期五。窗口锁只锁窗口:提醒、手机 Discord 照常(手机那边由手机遥控锁管)。
- **Discord 服务器频道里挡住私人资料**:在频道里问(别人也看得到回答),查邮件、日历、记账、笔记、找文件、剪贴板、账单、习惯、病毒扫描结果这些工具会直接被挡掉,请你改用私信;不只是靠提醒 Claude。
- **找到的文件只替你打开文件**:PDF、Word、Excel、图片、影音、压缩包才会直接打开;程序、脚本、快捷方式这类会执行东西的,只在文件夹里显示给你看。
- **接管鼠标键盘一看就知道**:星期五要动你的鼠标键盘前一定先弹确认框;接管的整段时间,窗口最上面有一条闪动的红条“🖱 星期五正在操控鼠标键盘:(原因)”,右下角也弹一个小通知;回答完、或者你动一下鼠标,就马上交还给你,红条收起来。每次接管和交还都记进安全记录(几点、为了什么、做了几步)。
- **安全记录**:齿轮设定 → 安全 里能看到最近的可疑事件(谁猜配对码、谁想让星期五读钥匙……),也能看和移除能用 Discord 控制星期五的账号、生成新的配对码。严重的事会马上显示在窗口并推到手机。完整记录在 `assistant/friday_security.log`。

### 记忆

**每周自动整理**:记忆有 8 条以上时,星期五每周请最便宜的 Haiku 看一遍,提出“哪几条可以合并”“哪条可能过时了(例如日期已经过去的安排)”“哪条分类放错了”,然后提醒你去齿轮设定 → 记忆整理 看。建议都是打勾的,不同意的取消勾选,再点“按勾选的改”;“全部忽略”就什么都不改。也可以点“现在整理”马上整理一次。每次大约不到 RM0.05,预算用完时不整理。

记忆保存在 `assistant/friday_memory.json`(已被 `.gitignore` 忽略,不会提交到 Git)。也可以直接让它“忘掉某件事”,或者用命令管理:

| 命令 | 作用 |
|---|---|
| `/memory` | 查看它记得的所有事 |
| `/forget 关键词` | 删除包含这个关键词的记忆 |
| `/clear` | 开始新话题(记忆保留,对话历史清空) |

想把记忆放到别的位置(比如网盘同步目录),在 `assistant/.env` 里写 `FRIDAY_MEMORY_FILE=路径`,或加参数 `--memory-file 路径`。

### 称呼

“星期五”默认称呼你为“老板”。想换个称呼,任选一种方式:

- 在 `assistant/.env` 里加一行 `FRIDAY_CALL_ME=队长`
- 或者运行时加参数 `--call-me 队长`(优先于 `.env`)

下面是手动安装和运行的方法(macOS / Linux 也适用)。

## 安装

需要 Python 3.9 及以上版本。

```bash
pip install -r assistant/requirements.txt
```

## 设置 API Key

先到 <https://console.anthropic.com/> 获取 API Key,然后任选一种方式配置。

**方式一(推荐):写在 .env 文件里**,只需设置一次:

```bash
copy assistant\.env.example assistant\.env      # Windows
cp assistant/.env.example assistant/.env        # macOS / Linux
```

用记事本(或任意编辑器)打开 `assistant/.env`,把 `在这里填你的Key` 换成你的 Key,保存即可。`.env` 已被 `.gitignore` 忽略,不会被提交到 Git。

**方式二:设置环境变量**

```bash
export ANTHROPIC_API_KEY=你的Key          # macOS / Linux
set ANTHROPIC_API_KEY=你的Key             # Windows CMD
$env:ANTHROPIC_API_KEY="你的Key"          # Windows PowerShell
```

两种方式都配置了时,以环境变量为准。如果想用别的位置的文件,可以加参数 `--env-file 路径`。

## 运行

```bash
python assistant/assistant.py
```

对话示例:

```
你好!我是你的 AI 小助理,有什么问题尽管问我。
命令:/clear 清空对话  /exit 退出

你:Python 里列表和元组有什么区别?
助理:……
```

### 命令

| 命令 | 作用 |
|---|---|
| `/clear` | 清空对话历史,开始新话题 |
| `/exit` 或 `/quit` | 退出(也可以按 Ctrl+C 或 Ctrl+D) |

回答过程中按 Ctrl+C 可以中断当前回答,不会退出程序。

### 可选参数

```bash
python assistant/assistant.py --effort high        # 思考更仔细(更慢)
python assistant/assistant.py --model claude-sonnet-5-5
python assistant/assistant.py --persona friday     # 切换为“星期五”
python assistant/assistant.py --persona friday --call-me 队长
python assistant/assistant.py --persona friday --voice --stt vosk   # 语音对话,离线识别
python assistant/assistant.py --persona friday --web               # 图形界面(--no-browser 只在后台运行,--port 指定端口)
```

`--effort` 可选 `low`、`medium`、`high`、`xhigh`、`max`。普通小助理默认 `low`(适合日常聊天),“星期五”默认 `medium`(要上网、动手做事,多想一点更稳)。
