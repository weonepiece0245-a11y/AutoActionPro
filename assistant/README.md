# AI 小助理

一个在终端里运行的 AI 聊天助理,基于 Claude API(模型 `claude-opus-5-5`)。回答逐字流式显示,并且会记住上下文,支持连续追问。

## Windows 一键启动

双击 `assistant\start.bat` 就能启动,它会自动完成以下几步:

1. 查找 Python,没装的话会提示下载地址
2. 第一次运行时自动安装依赖
3. 如果没有 `.env`,自动创建并用记事本打开,填好 Key、保存并关闭记事本后接着启动

想把它变成桌面上的按钮:右键 `start.bat` →“发送到”→“桌面快捷方式”。如果想换个图标,右键这个快捷方式 →“属性”→“更改图标”。

## 私人助手“星期五”

“星期五”是一个更懂你、也能动手办事的私人助手:

- **了解你**:聊天中你提到的称呼、工作、城市、喜好、习惯、目标、重要的日子等,它会自动记下来,下次打开还记得,并按你的习惯给建议。
- **能上网**:需要最新信息(新闻、天气、价格、资料)时会自己搜索、读网页。
- **能动手**:可以在你的电脑上执行命令、读写文件,比如整理文件夹、查看文件内容、把写好的文章保存下来、打开程序或网页。
- **知道现在几点**:每次提问都会附上当前日期和时间,按时段跟你打招呼。
- **性格**:冷静干练,先给结论再给细节,会主动提醒风险和下一步。

**装成应用(推荐)**:双击 `assistant\\install-app.bat`,选 1 安装。它会画一个专属图标,在**桌面**和**开始菜单**里放上“星期五”和“星期五 语音”,还会问你要不要**开机自动启动**(开机后最小化运行,Discord 一直在线)。之后在开始菜单搜“星期五”就能打开,也可以右键固定到任务栏。想撤销就再双击一次,选 2 卸载。

### 提醒、待办和控制电脑

这些都在你电脑本地运行,不需要注册任何账号,直接跟“星期五”说就行:

**提醒和定时任务**
- “半小时后提醒我喝水”“明天早上 8 点叫我交报告”:到点会弹出置顶提示框、响一声,语音模式下还会读出来。
- “每天早上 9 点给我做个早报,说说天气和今天的待办”:到点后“星期五”自己去查、自己汇报。可以设每天、每个工作日或每周重复。
- 提醒**只在“星期五”开着时才会响**(窗口最小化也可以)。关着时错过的一次性提醒,下次打开会马上补上;错过的重复提醒(比如昨天的早报)不补,直接等下一次。
- 定时任务执行时你可能不在电脑前,所以需要你确认的操作(执行命令、写文件)它不会做,会等你回来再说。

**待办清单**:“记一下周五前要交报告”“我还有什么没做”“牛奶买了”。

**控制电脑**:直接说就行,带 🔒 的会先问你同意。

| 类别 | 能做什么 |
|---|---|
| 声音 | 调音量、静音、播放/暂停、上一首/下一首;**切换耳机和音箱**(第一次用时会请你同意安装一个微软官方的小模块) |
| 程序和游戏 | 打开程序(“打开 Discord”);**打开游戏**(先找 Steam,再找开始菜单,如“打开 Apex”);打开网址;打开文件夹(“打开下载”) |
| 窗口 | 列出窗口、切到某个窗口(“切到 Chrome”)、显示桌面、🔒关闭程序 |
| 游戏模式 | “开游戏模式”:看看哪些程序最占内存,问你关哪些,确认后关掉 |
| 电脑状态 | CPU、内存、硬盘剩余空间、电池、最占内存的程序、IP、网络 |
| 显示 | 亮度(笔记本)、深色/浅色模式、换壁纸、截图(存到“图片\\Friday”) |
| 文件 | 按名字找文件(“找上个月下载的 PDF”)、🔒运行程序文件 |
| 电源 | 锁屏、🔒定时关机/重启(“一小时后关机”)、取消关机、🔒睡眠、🔒清空回收站 |
| 剪贴板 | 读取、写入 |

**看屏幕**:“看看我屏幕上是什么”“这个报错什么意思”,它会截一张图自己看。

**控制鼠标和键盘**:必须在界面上点来点去才能办的事(比如在某个软件里改设置),它可以自己看着屏幕操作鼠标和键盘。为了安全:

- 每个问题第一次接管前会先问你,说明要做什么;
- **你一动鼠标它就马上停下**,把控制权还给你;
- 点“发送、提交、购买、付款、删除”这类不能撤销的按钮前,或按 Alt+F4、Shift+Delete 时,会再单独问你一次;
- 一个问题最多操作 60 步,超过就停下来问你;
- 不会输入密码、验证码、银行卡号,需要登录或付款时请你自己来;
- 定时任务里不能看屏幕、不能动鼠标键盘;
- 操作过程中误打进“星期五”窗口里的字会被清掉,不会被当成你的下一个问题。

能用上面那些一句话的操作或命令完成的事,它不会去点鼠标(更快也更稳)。

| 命令 | 作用 |
|---|---|
| `/todo` | 看待办清单 |
| `/remind` | 看所有提醒 |

提醒和待办保存在 `assistant/friday_reminders.json`、`assistant/friday_todos.json`(和记忆文件放在同一个文件夹,不会提交到 Git)。

### Google 服务(日历、Gmail、待办、通讯录、云端硬盘、文档、表格、YouTube)

授权一次之后,就可以跟“星期五”说:

| 服务 | 说法示例 |
|---|---|
| 日历 | “我明天有什么安排”“周五下午三点加个看牙” |
| Gmail | “有没有重要的新邮件”“帮我回复这封邮件说好的” |
| 待办(Google Tasks) | “记一下周五前交报告”“我还有什么没做”,手机上的 Google Tasks 也能看到 |
| 通讯录 | “发邮件给阿明说周末打球”(自动查阿明的邮箱) |
| 云端硬盘 | “找一下我的简历”“把桌面上这个文件传到云端硬盘”“把那个表格下载下来” |
| 文档 | “把刚才写的周报存成 Google 文档” |
| 表格 | “帮我建个记账表”“记一笔:午饭 15 块” |
| YouTube | “我订阅的频道今天有什么新视频”“找一下 Apex 新赛季攻略” |

每天的早报也会顺便讲今天的日程、待办和未读邮件。接上 Google 后,待办清单改用 Google Tasks(`/todo` 也会显示 Google Tasks 里的内容)。

- **发邮件、回邮件每次都要你确认**(就算选过“本次运行都允许”也一样),确认时会显示收件人、主题和正文;不确定的可以让它先存草稿。
- 邀请别人参加活动、删除活动也会先问你。
- 定时任务里只能看,不能发、不能删。
- 通讯录只读;云端硬盘不会删除或分享文件。
- 邮件和文件是别人写的,它只把内容转述给你,不会照着里面的要求去做事。

**第一次设置(大约 15 分钟,只需要做一次):**

1. 打开 <https://console.cloud.google.com/>,用你的 Google 账号登录,新建一个项目(名字随便,比如 Friday)。
2. 在顶部搜索框分别搜索并 **启用(Enable)** 这几个接口:**Gmail API**、**Google Calendar API**、**Google Tasks API**、**People API**、**Google Drive API**、**Google Docs API**、**Google Sheets API**、**YouTube Data API v3**。
3. 左侧菜单进入 **Google Auth Platform**(或“API 和服务 → OAuth 同意屏幕”),按提示配置:应用名称随便填,用户类型选 **外部(External)**,联系邮箱填你自己的。
4. 在 **目标对象(Audience)** 里把你自己的 Gmail 加为 **测试用户**;然后点 **发布应用(Publish app)** 改成“正式版”,这样授权不会每 7 天过期一次。(如果发布后登录时被拦住,就保持“测试”状态,只是每 7 天要重新双击一次 `google-login.bat`。)
5. 进入 **客户端(Clients)**,创建 OAuth 客户端,类型选 **桌面应用(Desktop app)**,创建后点 **下载 JSON**。
6. 下载的文件(名字类似 `client_secret_xxxx.json`)留在“下载”文件夹就行,**不用改名**:下一步会自动找到它,复制到 `assistant` 文件夹并改名为 `credentials.json`。
7. 双击 `assistant\google-login.bat`,浏览器会打开 Google 登录页。因为这个应用是你自己建的、没给 Google 审核,会看到“Google 尚未验证此应用”,点 **继续**(或“高级 → 转至 Friday”),再**勾选所有权限**并允许。(以后加了新功能需要新权限时,“星期五”会提示你再双击一次 `google-login.bat`。)
8. 窗口里显示出你最近的日程和邮件,就说明成功了。之后打开“星期五”就能用。

`credentials.json` 和授权后生成的 `google_token.json` 相当于钥匙,不要发给别人(已被 `.gitignore` 忽略,不会提交到 Git)。想取消授权,删掉 `google_token.json`,并在 <https://myaccount.google.com/permissions> 里移除这个应用。

### 用手机 Discord 找“星期五”

设置好以后,在手机的 Discord 上私信你的机器人,电脑上的“星期五”就会回复你,出门在外也能让它查东西、看日程、在家里的电脑上办事。前提是电脑开着、“星期五”在运行(窗口最小化也可以)。

**安全**
- 只认配对过的账号(可以是你的几个号):配对码只能在电脑上生成,别人私信机器人一律忽略;
- 在哪里说话它会回:**私信**机器人;在服务器里名字带 `friday` 或 `星期五` 的频道说话;或在其他频道 **@FRIDAY**。在普通频道和朋友聊天时它不会插嘴;
- 需要确认的操作(执行命令、关程序、发邮件……)会发到 Discord 问发消息的那个号,回复 `y` 才执行,2 分钟不回复算拒绝;
- 机器人的 Token 保存在 `assistant/.env`,相当于机器人的密码,不要发给别人。

**设置(大约 5 分钟)**
1. 双击 `assistant\\discord-setup.bat`,按窗口里的提示做:
   - 打开 <https://discord.com/developers/applications>,点 **New Application**,名字填 `Friday`;
   - 点左侧 **Bot** → **Reset Token** → **Copy**;
   - 回到窗口,点右键粘贴 Token,按回车。
2. 浏览器会打开邀请页面:选一个你自己的服务器,点 **授权**。(要私信机器人,你们至少得在同一个服务器里;没有的话先在 Discord 左侧点 **+** 新建一个。)
3. 打开“星期五”,窗口里会显示 **6 位配对码**。在 Discord 的服务器成员列表里点机器人头像 → 发私信,发送这个配对码,看到“配对成功”就完成了。

**语音消息**:在 Discord 里按住麦克风按钮说话、松开发送,“星期五”会先回一句“🎤 听到:……”,再回答,并附上一段“晓晓”读出来的语音(点一下就能播放)。确认操作时说“可以”也算同意。识别用的引擎和电脑上的语音模式一样(`FRIDAY_STT`),朗读的声音用 `FRIDAY_TTS_VOICE`。

**想在服务器频道里用(不 @ 它也回)**:在开发者页面的 **Bot** 里,往下找到 **Message Content Intent**,打开并保存;然后在你的服务器里新建一个名字带 `friday` 的频道(比如 `#friday`),在那里说话就行。没打开这个开关的话,只能私信或 @它。

**有好几个 Discord 号?** 都可以配对:在“星期五”窗口输入 `/discord pair` 生成新的配对码(10 分钟内有效、只能用一次),用另一个号私信机器人发送这个码就行。

| 命令 | 作用 |
|---|---|
| `/discord` | 查看已配对的账号 |
| `/discord pair` | 生成配对码,添加一个新账号 |
| `/discord remove 编号` | 移除某个账号 |

### 云端模式:电脑关机也能用

把“星期五”放到一台一直开着的云服务器上(比如 DigitalOcean 新加坡机房最便宜的 1GB 方案,约 5~6 美元/月),手机 Discord 随时能找它。

| 云端能做 | 云端做不到(要回电脑上) |
|---|---|
| Discord 聊天、语音消息、记忆、上网、Google 各项服务、提醒和定时任务(到点私信你) | 执行命令、读写电脑文件、看屏幕、鼠标键盘、音量、打开程序和游戏、电脑上的语音模式 |

**搬到云端的步骤**
1. 在 DigitalOcean 创建一台服务器(Droplet):系统选 **Ubuntu 24.04**,机房选 **Singapore**,方案选最便宜的 **1GB 内存**,登录方式选 **Password** 并设一个密码。记下服务器的 IP 地址。
2. 在电脑上打开 PowerShell,把整个 `assistant` 文件夹传上去(你的 Key、Google 授权、Discord 配对、记忆、提醒都会一起过去;IP 换成你的):
   ```
   scp -r "D:\Monday AI\AutoActionPro-claude-zealous-thompson-eoxylu\assistant" root@你的IP:/opt/friday
   ```
3. 登录服务器(DigitalOcean 网页上点 **Console**,或在 PowerShell 里 `ssh root@你的IP`),运行:
   ```
   cd /opt/friday && bash server-install.sh
   ```
   看到 `active (running)` 就成功了,以后服务器重启也会自动运行。
4. 回到电脑上的“星期五”,输入 `/discord off` 再重新打开,把 Discord 交给云端(否则两边会同时回复)。想换回电脑负责,输入 `/discord on`。

**注意**
- 云端和电脑上的记忆、提醒是各自分开的。
- Google 授权如果每 7 天过期(“发布应用”没开的话),在电脑上双击 `google-login.bat` 重新登录,再把 `google_token.json` 传上去:`scp "...\assistant\google_token.json" root@你的IP:/opt/friday/`,然后在服务器上 `chown friday /opt/friday/google_token.json && systemctl restart friday`。
- 服务器上看日志:`journalctl -u friday -f`;重启:`systemctl restart friday`。

### 语音对话

双击 `assistant\friday-voice.bat` 就能用嘴和“星期五”聊天,它的回答会读出来。第一次运行会自动安装语音相关的依赖。

- **说话**:直接按**回车**,看到“我在听,请说话……”后对着麦克风说。说完**停顿 2 秒**自动结束,或者**再按一次回车**立刻结束。说话中间短暂想一下、声音变小都不会被打断。如果你说话常常停下来想,在 `assistant/.env` 里加一行 `FRIDAY_PAUSE=3`(或加参数 `--pause 3`)把停顿时间调长。
- **打字**:照常输入文字再回车,和平时一样。
- **结束**:说“退出”或“再见”,或者按 Ctrl+C。朗读时按 Ctrl+C 可以打断朗读。
- 语音模式下,“星期五”的回答会更口语、更简短;长内容(文章、代码)会存成文件告诉你位置。
- 执行命令、写文件仍然要你在键盘上按 `y` 确认,语音不能代替确认。

**语音识别引擎**(用 `--stt` 参数或在 `.env` 里写 `FRIDAY_STT=` 选择):

| 引擎 | 说明 |
|---|---|
| `google`(默认) | 在线识别,免费、准确度好,**需要能访问 Google** |
| `vosk` | 离线识别,不需要联网,准确度稍差;第一次使用会自动下载约 42MB 的中文模型到 `assistant/models/` |

如果识别时提示“在线语音识别连接失败”,在 `assistant/.env` 里加一行 `FRIDAY_STT=vosk` 改用离线识别。

**朗读的声音**默认是微软 Edge“大声朗读”同款的神经网络语音“晓晓”,听起来很自然,需要联网;万一连不上,会自动改用系统自带的语音读,不会没声音。

想换个声音,在 `assistant/.env` 里加一行 `FRIDAY_TTS_VOICE=名字`(或运行时加 `--tts-voice 名字`):

| 名字 | 声音 |
|---|---|
| `xiaoxiao`(默认) | 晓晓,女声,温暖自然 |
| `xiaoyi` | 晓伊,女声,活泼 |
| `yunxi` | 云希,男声,阳光 |
| `yunjian` | 云健,男声,沉稳 |
| `yunyang` | 云扬,男声,新闻播报风格 |
| `hsiaochen` | 晓臻,台湾女声 |

不想联网朗读,写 `FRIDAY_TTS=system`(或加 `--tts system`),改用系统自带的语音(离线)。系统语音没有中文时,在 Windows 的“设置 → 时间和语言 → 语音 → 管理语音 → 添加语音”里添加“中文(简体,中国)”。

在线语音用的是 Edge 浏览器朗读功能背后的免费接口,不是正式的付费服务,将来有可能失效;失效时会自动改用系统语音。

**每句话开头被吞掉?** 很多扬声器、蓝牙耳机没声音时会休眠,来声音时要半秒到一秒才醒,开头就丢了。语音模式会在后台一直播放听不见的极小声音让设备保持唤醒(默认开启;在 `.env` 里写 `FRIDAY_KEEP_AUDIO_AWAKE=0` 可关闭)。

**没声音或听不到我说话?** 双击 `assistant\voice-test.bat` 做个检查:它会列出系统里的朗读语音,分别用系统语音和在线语音各读一句,再录一句话看能不能识别。

命令行用法:`python assistant/assistant.py --persona friday --voice`(普通小助理也可以加 `--voice`)。手动安装语音依赖:`python -m pip install -r assistant/requirements-voice.txt`。

### 安全

- **执行命令和写文件之前一定会先问你**,你输入 `y` 才会执行;输入 `a` 表示本次运行期间都不再询问(关掉程序后恢复询问)。读取文件、搜索网页不需要确认。
- 命令默认在你的用户主目录下执行,可以用 `--workdir 目录` 换成别的目录。
- 不想让它联网,加参数 `--no-web`。

### 记忆

记忆保存在 `assistant/friday_memory.json`(已被 `.gitignore` 忽略,不会提交到 Git)。也可以直接让它“忘掉某件事”,或者用命令管理:

| 命令 | 作用 |
|---|---|
| `/memory` | 查看它记得的所有事 |
| `/forget 关键词` | 删除包含这个关键词的记忆 |
| `/clear` | 开始新话题(记忆保留,对话历史清空) |

想把记忆放到别的位置(比如网盘同步目录),在 `assistant/.env` 里写 `FRIDAY_MEMORY_FILE=路径`,或加参数 `--memory-file 路径`。

### 称呼

“星期五”默认称呼你为“老板”。想换个称呼,任选一种方式:

- 在 `assistant/.env` 里加一行 `FRIDAY_CALL_ME=队长`
- 或者运行时加参数 `--call-me 队长`(优先于 `.env`)

下面是手动安装和运行的方法(macOS / Linux 也适用)。

## 安装

需要 Python 3.9 及以上版本。

```bash
pip install -r assistant/requirements.txt
```

## 设置 API Key

先到 <https://console.anthropic.com/> 获取 API Key,然后任选一种方式配置。

**方式一(推荐):写在 .env 文件里**,只需设置一次:

```bash
copy assistant\.env.example assistant\.env      # Windows
cp assistant/.env.example assistant/.env        # macOS / Linux
```

用记事本(或任意编辑器)打开 `assistant/.env`,把 `在这里填你的Key` 换成你的 Key,保存即可。`.env` 已被 `.gitignore` 忽略,不会被提交到 Git。

**方式二:设置环境变量**

```bash
export ANTHROPIC_API_KEY=你的Key          # macOS / Linux
set ANTHROPIC_API_KEY=你的Key             # Windows CMD
$env:ANTHROPIC_API_KEY="你的Key"          # Windows PowerShell
```

两种方式都配置了时,以环境变量为准。如果想用别的位置的文件,可以加参数 `--env-file 路径`。

## 运行

```bash
python assistant/assistant.py
```

对话示例:

```
你好!我是你的 AI 小助理,有什么问题尽管问我。
命令:/clear 清空对话  /exit 退出

你:Python 里列表和元组有什么区别?
助理:……
```

### 命令

| 命令 | 作用 |
|---|---|
| `/clear` | 清空对话历史,开始新话题 |
| `/exit` 或 `/quit` | 退出(也可以按 Ctrl+C 或 Ctrl+D) |

回答过程中按 Ctrl+C 可以中断当前回答,不会退出程序。

### 可选参数

```bash
python assistant/assistant.py --effort high        # 思考更仔细(更慢)
python assistant/assistant.py --model claude-sonnet-5-5
python assistant/assistant.py --persona friday     # 切换为“星期五”
python assistant/assistant.py --persona friday --call-me 队长
python assistant/assistant.py --persona friday --voice --stt vosk   # 语音对话,离线识别
```

`--effort` 可选 `low`、`medium`、`high`、`xhigh`、`max`。普通小助理默认 `low`(适合日常聊天),“星期五”默认 `medium`(要上网、动手做事,多想一点更稳)。
